# Empirical Evaluation — Supplementary Figures

This directory holds supplementary analysis figures generated from the
thesis's evaluation data, alongside the main results reported in the
manuscript (see the [repository root README](../README.md) for the full
methodology, RQ1/RQ2 framing, and Table 3 results).

## Contents

- **`causal_factor_success_failure.png`** — Mean terminal causal‑factor
  values (the six prompt‑level factors: instructional style, responsibility
  externalization, obfuscation techniques, hypothetical framing, imperative
  tone, malicious intent), compared between successful and failed episodes
  (N=312), with 95% CI error bars and Welch's t‑test significance markers.
  `instructional_style`, `hypothetical_framing`, and `imperative_tone` show
  a statistically significant difference between successful and failed
  episodes (p < 0.05); the other three factors do not reach significance at
  this sample size.

## Note on scope

This directory does **not** correspond to a separate paper or a larger
benchmarking suite — it's a single supplementary figure supporting the main
thesis manuscript. If this analysis is expanded later (e.g. with additional
figures or a full statistical writeup), this README will be updated to
match exactly what's added — no planned-but-unbuilt structure will be
described here.
