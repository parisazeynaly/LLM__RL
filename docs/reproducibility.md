# Reproducibility Guide

## 1. Goal

This document describes how to reproduce the computational experiments
associated with CausalRLBreaker.

Because the experiments involve language-model inference APIs, exact
reproduction may depend on model availability, provider configuration,
network conditions, and API behavior.

---

## 2. Requirements

Recommended environment:

- Python 3.11
- Conda or Miniconda
- Git
- Access to the required inference API
- Sufficient computational resources for reinforcement learning experiments

---
